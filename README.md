## 🌟 О проекте

Telegram-бот для ведения личных заметок с категоризацией, карточной навигацией и умным поиском.

Бот позволяет:

- фиксировать события с автоматическим определением даты и времени
- создавать записи разных категорий с разной структурой данных
- просматривать заметки в виде отсортированного списка
- искать записи по ключевым словам
- листать карточки заметок
- редактировать дату
- добавлять и перезаписывать итоги

Каждый пользователь видит **только свои заметки**.

---

## 🧠 Архитектурная идея

Бот построен на асинхронной логике (Aiogram + PostgreSQL).

- Данные изолированы по пользователям
- Структура записей зависит от категории
- Карточный интерфейс реализован через inline-кнопки
- Поиск выполняется по всем текстовым полям записи
- Результаты всегда сортируются по дате (сначала новые)

## 📋 Просмотр записей

Все заметки отображаются в виде списка:
```bash
Категория — Название — Дата
```

- сортировка по дате (сверху самые свежие)
- компактный и читаемый формат
- внизу списка находится кнопка 🔎 Поиск


![List](docs/images/read_list.jpeg)

## 🔎 Поиск

- поиск по ключевому слову
- проверяются все текстовые поля записи
- выводится список найденных записей
- отображается количество найденных результатов
- сортировка сохраняется


![Search](docs/images/search.jpeg)

Все записи поиска при открытии имеют те же функции, что и в главном списке,
разница лишь в том, что список поиска будет состоять **только**
из записей с интересующим вас словом.

## 🗂 Карточки заметок

Каждая запись открывается как карточка.

## 📌 Итоги

Если итог ещё не добавлен — доступна кнопка:
- «Добавить итог»

Если итог уже существует:
- «Просмотреть итог»
- «Перезаписать итог»

При просмотре итог отправляется отдельным сообщением.

## 📦 Установка и запуск

### 1️⃣ Клонирование репозитория

```bash
git clone https://github.com/xenonim-ctrl/PyBot-for-notes.git
cd PyBot-for-notes
```
### 2️⃣ Установка зависимостей
```bash
pip install -r requirements.txt
```
### 3️⃣ Создание базы данных PostgreSQL

Убедитесь, что PostgreSQL запущен.

Создайте новую базу данных:
```SQL
CREATE DATABASE your_db;
```
### 4️⃣ Конфигурация

Создайте файл .env в корне проекта (используйте .env.example как шаблон):
```bash
BOT_TOKEN=your_telegram_bot_token
DB_HOST=localhost
DB_PORT=5432
DB_NAME=your_db
DB_USER=postgres 
DB_PASSWORD=your_password
```
### 5️⃣ Запуск бота
```bash
python bot.py
```

### 🧩 Кастомизация категорий

Структура категорий гибко задаётся в коде.

Вы можете:

- изменить список категорий
- изменить набор полей для каждой категории
- добавить новые типы записей
- изменить формат отображения карточек 
- или добавить что-то своё :)

Для этого необходимо отредактировать:
- логику создания записей
- обработчики состояний (FSM)
- структуру таблиц БД (при необходимости)

Бот спроектирован так, чтобы категории можно было адаптировать под любые задачи — от личного дневника до систематизированного трекера событий.
